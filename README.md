# Parrainages BND 2026

Simulateur d'affectation des parrainages entreprise–élève du Business Networking Day (TSE), par acceptation différée (Gale-Shapley côté élèves).

Priorité = 100 × niveau + 10 × engagement associatif + 1 × proximité master–entreprise. Les égalités sont départagées par un tirage au sort reproductible (graine).

## Utilisation

L'appli s'ouvre avec 40 élèves fictifs. Chacun peut modifier les règles, la table de proximité, les élèves et les places. Les modifications restent dans son navigateur. « Exporter la configuration » permet de partager ses réglages.
